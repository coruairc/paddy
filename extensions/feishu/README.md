# Paddy Feishu/Lark

Official Paddy channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from Paddy:

```bash
openclaw plugins install @openclaw/feishu
```

Configure the Feishu/Lark app credentials in Paddy, then connect the plugin to the chats where agents should receive and send messages.
