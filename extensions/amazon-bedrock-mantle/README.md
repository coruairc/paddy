# Paddy Amazon Bedrock Mantle Provider

Official Paddy provider plugin for routing Amazon Bedrock Mantle models through OpenAI-compatible provider flows.

Install from Paddy:

```bash
openclaw plugins install @openclaw/amazon-bedrock-mantle-provider
```

Use this plugin when your Bedrock deployment exposes Mantle-compatible model routing and you want Paddy agents to address those models through the Bedrock Mantle provider.
