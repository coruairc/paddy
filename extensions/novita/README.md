# Paddy NovitaAI provider

Official Paddy provider plugin for NovitaAI's OpenAI-compatible API.

## Install

```sh
openclaw plugins install @openclaw/novita-provider
paddy gateway restart
```

## Docs

See `docs/providers/novita.md` in the Paddy repository, or the published
docs at `https://docs.openclaw.ai/providers/novita`.
