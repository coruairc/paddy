# OpenCode Zen Paddy provider

Official Paddy provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
openclaw plugins install @openclaw/opencode-provider
paddy gateway restart
```

## Docs

See `docs/providers/opencode.md` in the Paddy repository, or the published
docs at `https://docs.openclaw.ai/providers/opencode`.
